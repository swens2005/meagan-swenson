## Language

All content must be written in United States English. This covers page text, meta tags, `llms.txt`, the README, code comments and identifiers. Use US spelling (color, organize, optimize, analyze, center, gray), and keep `og:locale` set to `en_US`.

Proper names keep their official spelling, even when it is British (for example, "EITCA Web Development Programme").

See [README.md](README.md) for project structure and editing notes.
